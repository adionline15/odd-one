RULES

4. Shared contracts are changed only through explicit coordination.
5. Prefer small integration batches over one final mega-merge.
6. Require tests for meaningful code changes.
7. Never request empty or artificial commits.
8. Commit count is a throughput target, not a reason to create meaningless work.
9. Production deployment is controlled separately from Git commit volume.
