# Daily Workflow

FOUNDER
-> state product goal

LEAD
-> inspect state
-> split into tasks
-> assign agents
-> define acceptance criteria

AGENTS
-> work independently
-> test
-> commit
-> push
-> hand off

INTEGRATION
-> combine completed batches
-> run integration tests
-> QA
-> merge to main

DEPLOYMENT
-> production build
-> deploy to Vercel
-> smoke test
-> report result

Daily target: 2,000+ meaningful commits when sufficient real work exists. Never trade code quality for an artificial commit count.
